REFERENCE / 기준 모형

표면은 내부를 채운 입체가 아닌 경계면을, 곡선은 두께 없는 선만 비교해요.

각 캐릭터의 모형과 판정을 모두 선택하세요. 두 명을 직접 조작하는 함께하기 모드예요.
경기 규칙과 수학

정답 판정을 한 캐릭터만 해당 라운드에서 승리하고 1점을 얻어요. 둘 다 맞으면 공동 승리, 둘 다 틀리면 승자 없이 다음 라운드로 진행해요. 마지막에 최고 점수 캐릭터가 우승해요. 모두 0점이면 우승자가 없어요.

표면: 연결된 닫힌 가향 표면에서 종수 0(구면)과 종수 1(토러스)을 비교해요. 곡선: 원·타원은 끝점이 없고, 선분·휘어진 선분은 끝점이 2개예요. 표면과 곡선은 차원이 달라 위상동형이 아니에요. 곡선의 화면상 두께와 끝점 표식은 비교 대상에 포함하지 않아요.
