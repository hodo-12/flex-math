# 위상 숨바꼭질 · Topology Hideaway

두 캐릭터 중 하나를 선택하고 3D 장난감 방에서 도넛과 위상동형인 표면 3개를 찾는 웹 게임입니다.

## 실행
Node 18+와 Python 3 환경에서 `npm test`로 판정 로직을 검사하고 `npm start` 후 http://localhost:8080 에 접속합니다. 빌드와 API 키가 필요 없습니다. Three.js 0.170.0을 로컬에 포함했습니다.

## 기능
- 이전 영상의 얼굴 이미지 2종, 얼굴이 바뀌지 않는 빌보드 방식 아바타
- 레벨 선택, 첫 레벨 6개 물건과 정답 3개
- 물건 클릭 → 아바타 이동 → 회전 가능한 모형 관찰 → 같은/다른 구조 판정
- 정답·오답 이유, 중복 수집 방지, 미션 완료, 다시 하기, 클리어 기록
- 모바일 터치와 키보드로 선택 가능한 물건 버튼
- Web Audio로 직접 합성한 16음 배경음악, 정답 효과음, 음소거

## 수학적 기준
모두 두께 있는 물체의 전체 경계 표면을 비교합니다. 정답은 사각 고리, 길쭉한 고리, 손잡이 컵(종수 1)입니다. 공과 그릇은 종수 0, 두 구멍 블록은 종수 2입니다. 컵의 안·밖·테두리를 하나의 표면으로 보며 입구의 움푹 팬 부분은 별도 관통 구멍으로 세지 않습니다. 이 레벨의 닫힌 연결 가향 표면에 적용하는 분류이며 임의의 모든 위상공간을 구멍 수만으로 분류하지 않습니다.

## 소스 구성 / 다음 단계
- `state.js`: 레벨 물건과 정답 데이터, Mission 상태
- `app.js`: 3D 모형, UI 흐름, 이동, 관찰, 합성 음악
- `style.css`: 반응형 UI
- `hood.png, smile.png`: 사용자가 요청한 기존 캐릭터 얼굴 이미지
- `mission.test.js`: 판정·중복·초기화 검사

다음 레벨은 objects 데이터와 레벨별 목표를 분리해 추가할 수 있습니다. 현재 레벨 2는 준비 중으로 표시되며 플레이는 레벨 1만 가능합니다. 아바타는 3D 몸체 + 2D 얼굴 텍스처이며 완전한 입체 얼굴 리깅이나 얼굴 인식 기능은 포함하지 않습니다. 정답일 때 관찰 모형을 도넛으로 교체합니다. 컵에서 도넛으로의 연속적인 메시 변형은 다음 개발 단계입니다.

## GitHub Pages

Settings → Pages → Deploy from a branch → main / (root)를 선택합니다. 루트의 index.html을 그대로 서비스하며 빌드가 필요 없습니다. 모든 게임 에셋은 상대 경로이며 3D 라이브러리도 저장소에 포함합니다.
